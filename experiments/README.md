# Retained experiment runs

[2026-10-28 catalog](run-archive-2026-10-28/README.md) records the baseline,
candidate, profiling, exploratory, and confirmation run history through the
2026-10-28 import. Git retains source code, summaries, failed and interrupted
attempts, timing samples, and environment observations. Bulky numerical arrays,
generated weight layouts, and worker tensor dumps remain in local artifact
storage; their sizes, SHA256 hashes, and relative locations are in the manifest.

This is an evidence archive, not a new evaluator report. Original records retain
their own contracts, source identities, scope, limitations, and dispositions.
Archiving does not establish a speedup or candidate acceptance.
