# Final round-two candidate

The C2 vocabulary layout and MoE arithmetic remain byte-for-byte unchanged. The new request driver builds and submits the next actual greedy step before Python observes its predecessor, overlapping host graph construction with GPU execution. There are 127 asynchronous submissions, 128 emitted tokens and 129 forwards for each locked request. Prefill, the first-token boundary, final GPU drain and peak memory remain accounted.

The same scheduling core exposes a correctness-only tensor-reference capture hook for 8- and 128-output qualification. That hook is absent from timing. Native full-model logits, routes, tokens, cache values/metadata, actual forward count and submission count must be checked before timing; CPU order tests are not native proof.

This is the third and final substantive candidate in the authorized round. No speedup or acceptance is claimed.
